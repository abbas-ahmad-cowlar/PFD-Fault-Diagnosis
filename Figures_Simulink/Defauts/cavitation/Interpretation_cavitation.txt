INTERPRÉTATION DES RÉSULTATS - CAVITATION
=====================================================

Signal : data_signaux_simulink/cavitation_001.mat (modèle Simulink, 3600
tr/min soit 1X = 60 Hz, charge 70 %, température 60 °C, sévérité
0.7, fs = 20480 Hz, durée 5 s). Comparaison à la référence saine de
la Phase 1, mêmes méthodes et mêmes critères (significatif à partir
de 3 dB ; règles indicatives du cadre d'étude).

Physique du défaut : l'implosion des bulles de cavitation dans le
film d'huile produit des bouffées d'énergie haute fréquence dans
la bande 1500-2500 Hz, visibles sur les Figures 5 à 8 (bande élargie
à 0-3000 Hz) et sous forme de colonnes dans le spectrogramme.

Résultats mesurés :
  RMS = 0.0454 (sain : 0.0421)
  Kurtosis = 6.83 (sain : 2.98) ; facteur de crête = 9.31
  Excès au-dessus du plancher médian local : 1X +0.1 dB,
  2X +2.2 dB, 3X -0.8 dB, zone sous-synchrone +0.3 dB
  Écarts par rapport au sain : bande 1500-2500 Hz +5.31 dB,
  bande 500-2000 Hz +2.99 dB

Note de lecture du kurtosis : lorsqu'une composante périodique
domine le signal (balourd, tourbillonnement, stick-slip), le
kurtosis global descend EN DESSOUS de 3 (une sinusoïde pure a un
kurtosis de 1.5) ; un kurtosis inférieur à 3 signale donc ici une
composante périodique dominante, et non un signal plus sain. Les
défauts impulsifs (cavitation) l'élèvent nettement au-dessus de 3 ;
une modulation d'amplitude (usure) peut aussi le porter légèrement
au-dessus de 3 sans impulsivité.

SIGNATURE CONFIRMÉE : bande 1500-2500 Hz à +5.3 dB au-dessus du sain.

Les conclusions décrivent le comportement du défaut tel qu'encodé
par le modèle de simulation ; elles servent de référence interne
pour la suite de l'étude (défauts mixtes, Phase 3).
