--- HOW TO USE (Step by Step) ---

Step 1: Open MATLAB R2024b
Step 2: Navigate to this folder
        >> cd path/to/this/folder

Step 3: Open the model
        >> open_system(fullfile(pwd, 'model', 'PFD_Signal_Generator.slx'))

Step 4: Change fault type (double-click Fault_Injection,
        then double-click Fault_Type and change the value)
        Fault codes:
          1 = Sain (Healthy)
          2 = Desalignement (Misalignment)
          3 = Desequilibre (Imbalance)
          4 = Jeu (Clearance)
          5 = Lubrification (Lubrication)
          6 = Cavitation
          7 = Usure (Wear)
          8 = Oil Whirl
          9 = Mixte: Desalignement + Desequilibre
         10 = Mixte: Usure + Lubrification
         11 = Mixte: Cavitation + Jeu

Step 5: Click the green "Run" button (or press Ctrl+T)
        The simulation runs for 5 seconds at 20,480 Hz.

Step 6: Double-click the Scope block to see the waveform.

Step 7: The signal is saved to workspace as "x_sim".
        You can plot it with:
        >> plot(x_sim)

--- MODEL ARCHITECTURE ---

Operating_Conditions -> Speed, Load, Temp -> Sommerfeld number
Base_Signal          -> Baseline vibration (white noise)
Fault_Injection      -> 11 fault types (MATLAB Function block)
Severity_Control     -> Severity 0-1 with optional temporal evolution
Transient_Behavior   -> Speed ramp / Load step / Thermal expansion
Noise_Model          -> 8 noise layers (measurement, EMI, pink, etc.)
Signal_Sum           -> Base + Fault*Severity*Transient + Noise
Quantizer            -> ADC quantization effect (0.001 step)

--- VERIFICATION ---

See screenshots/ folder for model views and simulation results.
Each fault type produces the expected spectral signature based on
the hydrodynamic bearing physics (Sommerfeld theory).
